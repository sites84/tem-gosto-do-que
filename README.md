# Tem Gosto do Q

**Tem Gosto do Q?** é um projeto de descoberta gastronômica baseado em uma pergunta simples: **tem gosto de quê?**

O site vai investigar alimentos, ingredientes, carnes, frutos do mar, insetos, animais consumidos como alimento e outros itens, reunindo sabor, textura, relatos de quem já experimentou, origem, história, cultura, preparo e formas de consumo.

## Princípio do projeto

O site deve diferenciar fatos documentados de experiências pessoais. Relatos serão utilizados como relatos e serão sintetizados sem transformar uma opinião isolada em verdade.

## Desenvolvimento

O projeto será desenvolvido em etapas pequenas e verificáveis para reduzir regressões e retrabalho.

- GitHub: código e versionamento
- GitHub Pages: publicação inicial do frontend
- Supabase: banco de dados e serviços necessários
- Primeiro alimento-piloto: azeitona
- Segundo piloto: alimento incomum, como escorpião

A arquitetura detalhada está em [`docs/FASE-0-ARQUITETURA.md`](docs/FASE-0-ARQUITETURA.md).

## Regra importante

Não alterar grandes partes do projeto de uma vez. Cada etapa deve preservar o que já funciona e ser verificada antes da próxima alteração.
